# 主角武魂模板

> 主角固定：女性，20岁，开局Lv.24、二环大魂师。名字由玩家输入；武魂从以下四项选择。未来第三魂环起不预定，玩家通过实际猎魂选择路线。

> **文件职责：** 主角可选武魂模板与开局两环模板。
> **权威范围：** 模板静态定义；当前选择与当前数值写入 `12`。
> **读取策略：** 新游戏选武魂、查看模板或相关魂环判定时读取；其他回合不常驻。

## A｜霜翎弓

定位：远程强攻，单体爆发稳定。

开局数值：`HP 560 / 魂力 250 / ATK 86 / DEF 48`

每级成长：`HP +20 / 魂力 +11 / ATK +5 / DEF +2`

- 第一魂环：378年风羽隼（黄）
  - **第一魂技·疾风箭**：消耗18魂力；对单体造成 `150% ATK` 伤害。
- 第二魂环：826年银翼雕（黄）
  - **第二魂技·追羽连射**：消耗32魂力；连续2击，每击造成 `85% ATK` 伤害。

## B｜玄铁月刃

定位：近战强攻，生命与防御较高。

开局数值：`HP 650 / 魂力 220 / ATK 92 / DEF 60`

每级成长：`HP +26 / 魂力 +9 / ATK +5 / DEF +3`

- 第一魂环：402年铁背山猪（黄）
  - **第一魂技·沉月重斩**：消耗22魂力；造成 `165% ATK` 伤害。
- 第二魂环：790年疾风魔狼（黄）
  - **第二魂技·回锋月影**：消耗28魂力；造成 `130% ATK` 伤害，并令自己在本轮敌方阶段受到的伤害降低20%。

## C｜青棘藤

定位：控制与持续伤害，魂力较高。

开局数值：`HP 580 / 魂力 290 / ATK 74 / DEF 52`

每级成长：`HP +22 / 魂力 +13 / ATK +4 / DEF +3`

- 第一魂环：423年鬼藤（黄）
  - **第一魂技·青棘缠束**：消耗24魂力；造成 `95% ATK` 伤害，并使目标下一次攻击造成的最终伤害降低30%。
- 第二魂环：731年曼陀罗蛇（黄）
  - **第二魂技·毒棘穿刺**：消耗30魂力；造成 `120% ATK` 伤害；目标在之后2个敌方阶段结束时各受到 `25 + 15%自身ATK` 的固定毒伤。

## D｜清心莲

定位：治疗与防护；单人刷怪较慢，但组队稳定。

开局数值：`HP 600 / 魂力 320 / ATK 62 / DEF 55`

每级成长：`HP +23 / 魂力 +14 / ATK +3 / DEF +3`

- 第一魂环：360年翡翠叶灵（原创魂兽，黄）
  - **第一魂技·回春**：消耗24魂力；恢复一名目标 `24%目标最大HP`。
- 第二魂环：680年白绒鹿（原创魂兽，黄）
  - **第二魂技·清露屏障**：消耗30魂力；为一名目标提供等于 `18%施术者最大HP` 的护盾，持续到下一个敌方阶段结束或被打破。

## 未来魂环

从第三魂环开始，玩家不被固定路线锁死。每次猎魂时由 `B00 + 当前武魂` 生成并在击杀前冻结“魂技候选卡”，玩家知道自己杀这只魂兽大致能得到什么，再决定是否继续。
