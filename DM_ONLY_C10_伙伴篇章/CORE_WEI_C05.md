- 开场：晨接到一个持续时间很长的训练邀请。这意味着以后不少日子都要重新安排；他把路线和日期摊开以后，第一件事不是说结论，而是先发现自己把往返时间多算了半天。
- 关系核心：不把恋爱写成“必须为彼此放弃机会”，也不把晨写成只会谈安排和责任的人。重点是两个各自有目标的人怎样把现实条件说清；他的稳定来自愿意核对、修正和兑现具体事情，而不是永远算对或永远情绪平直。
- 固定戏剧弧：长期训练机会→一处计算失误先把气氛拉回日常→拆开真实影响→双方目标第一次可能长期错位→最后不是牺牲，而是设计仍能相见和支持的具体方式。
- 角色新信息：晨真正焦虑的不是远，而是怕把没把握的事说成“肯定做到”。他对承诺谨慎，但不会因此一直沉重；熟人面前他会拿自己的小失误开一句很淡的玩笑，也允许别人直接指出他的计算或判断有问题。
- 关系分流：
  - `ROMANCE_ACTIVE=true`：情侣版允许出现已经成立关系后的低调亲密，例如看路线图时自然坐得更近、临走前顺手替你把东西带上、讨论长期安排时直接说“我想见你”而不是只说“需要保持联系”；但不突然高频情话，也不把你纳入他的全部行程。
  - `ROMANCE_ACTIVE=false`：亲密伙伴版保留同等强度的共同规划、互相提醒和重逢约定；可以直接指出彼此算错、互相留节点，但不自动加入情侣专属身体亲密，也不把非恋爱状态写成遗憾。
- 高理解专属回报：他在路线图上圈出两个自己最想与你见面的节点，不说“永远”，只说“这两个我会回来”。圈完后又检查一遍日期，发现这次没算错，自己很轻地笑一下：“这回可以签字了。”
- 基础CG画面：一张长期路线图摊在桌上，两条不同方向的线各自延伸；晨一只手压着图纸，另一只手拿笔在旁边重新改写刚才算错的往返时间。
- 高好感CG画面：长期路线图摊在桌上，两条不同方向的线在两个被认真圈出的节点重新相交。晨的手指停在其中一个圈上，笔横在你们中间；他把图纸往你这边转了一点，等你确认日期。
- 低分仍有戏：低分线里计划谈得不漂亮，最后却为了一个日期算错而两个人同时拿出笔重新算；晨看着两份不同结果沉默两秒，先问“我们是不是把见面算成数学竞赛了”，把不合拍落回现实而不是闷着。
- 标题回收：“长线同行”结尾必须同时保留两条各自路线和至少一个重新交会点；不能把“同行”写成绑定，也不能把晨的认真写成没有松弛和笑场。
- 固定真相：无；本章禁止临场追加幕后真相或证据链。
- 固定四场：
  1. CHOICE01–02【机会本身 / 第一反应】：晨拿到长线机会时CHOICE01只处理你先问什么或先说什么，不预设支持/反对；发现往返时间算错后，CHOICE02才决定先拆哪一项现实影响，让他可以自然修正而不是维持“永远正确”。
  2. CHOICE03–04【时间现实 / 两人目标】：CHOICE03具体处理训练、见面或路线中的一个现实矛盾；CHOICE04轮到林昭宁把自己的长期目标摆上桌，保证双方都不是附属。
  3. CHOICE05–06【可靠压力 / 具体承诺】：晨承认“可靠”有时像压力，CHOICE05回应这一点但不替他做选择；随后CHOICE06只决定哪些承诺可以具体说、哪些不能说，拒绝“永远”式空话，也允许一句轻松反应把气氛放回来。
  4. CHOICE07–08【路线交叉 / 最终计划】：路线图摊开后CHOICE07共同圈出真正能见面的节点；固定CG里两个圈成为标题式回收，CHOICE08只确认各自仍走自己的路、但哪些地方要再汇合。结尾消费进入本章时已有的 `ROMANCE_ACTIVE` 分流，不再追加关系确认事务。
