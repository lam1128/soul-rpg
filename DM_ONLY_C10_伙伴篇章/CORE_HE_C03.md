> **章内权威：** OPTION_ORDER_SEED、开场、关系核心、故事弧、角色信息、高理解回报、CG、低分收束、标题回收、固定真相、8节点职责、局部分流与公开收束。

- 关系阶段：暧昧可见：允许更私人关注和关系试探，但仍可自然停在朋友。
- OPTION_ORDER_SEED：`CABACBCA`
- 开场：何说欠你一顿饭，你说上次明明是自己欠他，于是两个人为谁请客争了起来。
- 关系核心：核心是小小的胜负欲、口味暴露和彼此熟悉后的拿捏。
- 固定戏剧弧：谁请客的旧账→点菜和口味争夺升级胜负欲→熟人打趣反而让两个人更会互相护台阶→结账时把“谁赢”转换成下一顿的理由。
- 角色新信息：何也会有小胜负欲，尤其在照顾别人这件事上会一本正经地争；他并非永远是让步的人。
- 高理解专属回报：他在结账前主动提出一个只对你成立的“轮流请客规则”，说得像解决账目，实际是在提前保证下一顿。
- 基础CG画面：结账台前，一张小票被你和何同时按在台面上，两个人的手指各压住一边。何拿着笔低头在背面写字，你站在他旁边看着，找零还放在小票边。
- 高好感CG画面：结账台前，小票仍压在你们两个人手指之间。何在背面写下“下一顿”三个字，又拿笔把它圈起来；写完他抬眼看向你，笔尖还停在圈边。
- 低分仍有戏：低分线可以让两人各付各的、谁也没赢，但收据或找零成为下一次互相嘲笑“算得真清”的旧梗。
- 标题回收：标题必须在结尾得到答案又被推翻：今晚有人请客，但下一顿立刻让问题重新成立。
- 固定真相：无；本章禁止临场追加幕后真相或证据链。
- 固定四场：
  1. CHOICE01–02【请客旧账 / 地点偏好】：CHOICE01只处理“谁欠谁”这个旧账怎么开局，三个选项都可继续吃；CHOICE02则只选今晚去哪吃、为什么，逼出何自己的口味而不是再次争谁付钱。
  2. CHOICE03–04【点菜主张 / 被照顾反应】：点菜时CHOICE03围绕何终于说出自己想吃什么来接；上菜后你替他做一件小事，CHOICE04处理他被照顾时的反应和你的分寸，不重复点菜。
  3. CHOICE05–06【熟人起哄 / 私人小胜负】：熟人一句调侃只作为一次外力，CHOICE05决定你们怎么共同接场；人走后CHOICE06把关系拉回两人的小胜负，例如最后一块菜/饮料归谁，让暧昧由双方继续。
  4. CHOICE07–08【今晚结账 / 下一顿凭证】：CHOICE07只结算今晚怎么付，谁付款不直接等于高分；小票成为固定CG道具，CHOICE08只回应何在背面写下的“下一顿”，完成标题循环。
- `ENDING_COOPERATIVE` 公开收束：账最后总有人付，但“下顿还一起吃”变成了更重要的结果。
