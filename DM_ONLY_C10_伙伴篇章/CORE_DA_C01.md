> **读取边界：** 仅当 `ACTIVE_EPISODE_ID` 或本轮明确进入目标等于本章ID时读取；运行其他章节时禁止预读本文件。
> **章内权威：** OPTION_ORDER_SEED、开场、关系核心、故事弧、角色信息、高理解回报、CG、低分收束、标题回收、固定真相、8节点职责、局部分流与公开收束。

- 关系阶段：熟悉建立：可以轻松、有默契，但不强制暧昧。
- OPTION_ORDER_SEED：`ACBCABCB`
- 开场：街角小舞台临时缺一个搭档，大张口就把你点了上去。
- 关系核心：表演、翻车和临场救场制造大量笑点，但关系重点是你是否愿意和他一起丢脸，同时能在他的高速度里真正占住自己的舞台位置。
- 固定戏剧弧：被临时点上台→准备越救越乱→正式表演出现真失误逼出即兴默契→散场后笑到没力气，在没有观众时留下一个只属于搭档的信号。
- 角色新信息：大在台上很敢闹，但真正把搭档当自己人时会主动给对方留发挥空间；另外他越临近正式上台越容易话多，很多荒唐点子既是兴奋也是他自己消化紧张的方式。
- 高理解专属回报：关键包袱前，他看见你已经起势便真的退开半步，让你把最重要的即兴完整做完；散场后不再解释“为什么让”，只在那块坏掉的牌子边缘敲两下你们刚约好的接话暗号。此时已经没有节目需要接。
- 记忆画面锚点（CG）：观众散尽后的后台台阶，两个人坐在同一级台阶，断掉的“年度最可靠魂师 / 临时维修中”牌子斜放在中间；大低头在牌子边缘敲两下接话暗号，你若处于高理解线则回敲一下，他偏头笑却不再补梗。画面结束后禁止再用对白解释“这代表我们是搭档”。
- 低分仍有戏：低分线里你们互相没接住，冷场三秒后大直接把冷场编进节目，反而全场最响；台下他再用坏牌子重演一次这三秒，让失败成为真正共同作品。
- 标题回收：“临时舞台”结尾必须让台上的某个翻车梗在台下再次出现；高理解线还要让“临时搭档”通过无观众的暗号动作获得新的含义。
- 固定真相：无；本章禁止临场追加幕后真相或证据链。
- 固定四场：
  1. CHOICE01–02【参与方式 / 舞台分工】：CHOICE01只决定你以什么姿态接下这次临时上台——主动玩、先问框架或要求稳一点，但都完整进入本章；CHOICE02才决定你和大如何分舞台、谁先控开场与谁拥有独立发挥空间，不能把两题都写成“要不要上”。
  2. CHOICE03–04【互相挖坑 / 风险尺度】：CHOICE03只处理随机道具挑战怎么玩、敢不敢互相选离谱道具；CHOICE04才明确这场允许失控到什么程度、何时该放弃一个梗保住整场，一题玩心、一题风险，不重复舞台分工。
  3. CHOICE05–06【真实救场 / 即时信号】：真失误发生后，CHOICE05让玩家实际接住事故；CHOICE06才建立一个简短接话信号，解决“同时想到包袱”这一具体问题。之后不得再次询问“大以后该不该收着点”。
  4. CHOICE07–08【私人信息 / 下一次邀请】：散场后由大自然暴露“越临开场越话多”的私人反差，CHOICE07处理你怎么接这件事；随后进入固定CG锚点。CHOICE08只回答他以后还能不能叫你，不再开第二次搭档原则会议。
- `ENDING_COOPERATIVE` 公开收束：一起丢过一次脸以后，很多距离都会莫名其妙变短；最好的部分不是把合作原则讲明白，而是没人看着时那个暗号还会被敲出来。
