- 关系阶段：暧昧可见：允许更私人关注和关系试探，但仍可自然停在朋友。
- OPTION_ORDER_SEED：`ACBCABCB`
- 开场：鸥要进城补箭袋、护腕和几样杂物，问你有没有空一起。
- 关系核心：买东西只是借口；真正内容是偏好、审美、互相拆台和一段没有任务目标的相处。
- 固定戏剧弧：陪买装备的明确任务→审美与预算互相拆台→等待/天气迫使行程失控并暴露私人偏好→返程留下一个只有双方知道为什么买的小物件。
- 角色新信息：鸥有自己的审美和“明明实用却会偷偷挑好看”的一面；她也可能为了一个不必要的小东西犹豫很久。
- 高理解专属回报：她主动替你挑中一件与你习惯有关的小物件，随后又装作只是顺手；玩家若接住，她会把自己的同类偏好也坦白出来。
- 基础CG画面：城里檐下刚躲过一阵天气变化，你和鸥手里各拿着一件原本没在清单上的小东西。她低头看着替你挑的那件，在自己掌心里转了半圈，又抬眼看向你伸出的手。
- 高好感CG画面：城里檐下，鸥把替你挑的那件小东西直接压进你掌心，指尖在你手边停了一拍。她随即偏开视线，手里还拿着自己那件清单外的小物件，嘴上继续一本正经地评价实用性。
- 低分仍有戏：不合拍时，小物件仍可以变成“你挑的真难用/我早说了”的长期吐槽素材，让半日不是白走。
- 标题回收：“半日”在结尾由她主动评价：明明只办了几件小事，却把下一次半日也顺手预留出来。
- 固定真相：无；本章禁止临场追加幕后真相或证据链。
- 固定四场：
  1. CHOICE01–02【同行理由 / 预算审美】：CHOICE01决定你把这次进城当纯跑腿、顺便玩还是主动陪她挑；进第一家店后，CHOICE02围绕一件“实用但不好看 / 好看但非必要”的物件做取舍，让她的审美和你的标准真正碰一下。
  2. CHOICE03–04【试用玩笑 / 非必要加购】：试护具或配件时，CHOICE03处理彼此评价、互损和是否敢给具体意见；随后鸥在清单外的小东西前犹豫，CHOICE04只处理你如何参与这个“没必要但有点想要”的决定，不重复预算争论。
  3. CHOICE05–06【计划打乱 / 私人偏好】：天气或排队把计划打散，CHOICE05决定临时空出来的时间怎么用；坐下等的时候她暴露一个生活偏好，CHOICE06只处理你是否接住并交换自己的偏好，不把谈话写成关系规则。
  4. CHOICE07–08【小物件回收 / 下一次半日】：返程前两件清单外小物件形成callback，CHOICE07决定你怎么接她“顺手替你挑”的动作；CHOICE08只处理她把“半日”再次留给你的轻邀请，不讨论详细日程。
- `ENDING_COOPERATIVE` 公开收束：半日没有解决什么大事，却让“下次一起”变得很自然。
