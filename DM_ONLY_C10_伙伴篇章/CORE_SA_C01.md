> **章内权威：** OPTION_ORDER_SEED、开场、关系核心、故事弧、角色信息、高理解回报、CG、低分收束、标题回收、固定真相、8节点职责、局部分流与公开收束。

- 关系阶段：熟悉建立：可以轻松、有默契，但不强制暧昧。
- OPTION_ORDER_SEED：`BCACABAC`
- 开场：撒在食堂排队时突然提出一个荒唐命题，还给你三分钟准备。
- 关系核心：题目越无聊越好，真正看点是两个人越吵越熟，以及谁会先笑场。
- 固定戏剧弧：荒唐命题开辩→围观与临时规则让胜负欲升温→某句话意外碰到真实偏好→计时结束后两个人谁都不肯真正结束。
- 角色新信息：撒会为了很无聊的题目认真到过头，也会在自己说太满时快速认账；他的聪明可以很好笑，不只用来赢。
- 高理解专属回报：三分钟到了他主动加一句“本题允许加时”，其实只是还想和你继续吵；若被拆穿会立刻换个更荒唐理由。
- 基础CG画面：食堂桌边的三分钟沙漏已经完全漏完，撒的手停在沙漏旁边，指尖碰着底座。周围围观的人已经散开，你们面前还摊着刚才写过的几张论点纸。
- 高好感CG画面：三分钟沙漏已经漏完，撒当着你的面把它翻过来重新计时，另一只手还压着没收起来的论点纸。他抬头看你，嘴上宣布“本题允许加时”，周围已经没有围观的人。
- 低分仍有戏：低分线里两人真的吵得不太愉快，但最后发现最初命题都记错了，只能同时沉默，再各自不服地笑。
- 标题回收：“三分钟”必须在结尾再次被计时，并被证明根本不够你们把话说完。
- 固定真相：无；本章禁止临场追加幕后真相或证据链。
- 固定四场：
  1. CHOICE01–02【接不接招 / 辩题立场】：三分钟小辩题丢过来，CHOICE01决定你怎么接他的挑衅；CHOICE02才选具体立场/论法，让“敢不敢玩”和“怎么辩”分开。
  2. CHOICE03–04【临时规则 / 反击方式】：围观者加规则后CHOICE03处理你接受、钻空子还是反提条件；撒开始抢节奏时CHOICE04只决定你怎么反击他的语言优势，不重复立场。
  3. CHOICE05–06【真实偏好 / 不必赢】：辩题意外碰到真实生活偏好，CHOICE05处理你是否承认“这不是为了赢”；撒也露出一个真偏好后CHOICE06只接这件事，不把认真瞬间立刻变告白。
  4. CHOICE07–08【沙漏翻面 / 下一题】：三分钟结束，CHOICE07处理谁先承认还没吵够；固定CG中撒把沙漏翻回去，CHOICE08只决定下一题/赌注是什么，把标题的“三分钟”变成主动加时。
- `ENDING_COOPERATIVE` 公开收束：你们谁也没赢，但都把下一场约好了。
