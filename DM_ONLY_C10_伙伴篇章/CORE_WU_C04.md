- 关系阶段：暧昧推进：关系更近，但不提前执行确认门。
- OPTION_ORDER_SEED：`CBACBACA`
- 开场：昕因为一次不理想的训练结果取消了原本的休息安排，打算独自加练。
- 关系核心：重点不是劝她积极，而是尊重她的挫败、让她自己决定什么时候停。
- 固定戏剧弧：训练结果不理想→她把休息改成加练→现实疲劳让“坚持”与“停下”都不再是标准答案→她自己选定下一步并允许你看见决定过程。
- 角色新信息：昕面对挫败时会固执，但不是为了证明给别人看；她真正不喜欢的是别人抢走她判断“我还能不能继续”的权利。
- 高理解专属回报：高理解线中她自己先说“今天到这儿”，然后反过来问你要不要吃东西，用主动结束训练证明停下不是被劝服。
- 记忆画面锚点（CG）：训练场暮色里，她自己先收起装备，把水递给你后问“要不要吃点东西”；高理解版“今天到这儿”由她先说出口。
- 低分仍有戏：低分线可让她继续练完，但第二天拿某个酸痛动作自嘲“昨天赢了训练，今天输给楼梯”，让摩擦有后续性。
- 标题回收：“停一天也没关系”要由她本人在结尾给出自己的版本，不能由玩家教育式总结。
- 固定真相：无；本章禁止临场追加幕后真相或证据链。
- 固定四场：
  1. CHOICE01–02【异常看见 / 陪伴位置】：从她重复训练或明显慢下来进入，CHOICE01决定是否指出；CHOICE02只处理你待在场边、一起练最后一轮还是先去拿水，回答的是“怎么在旁边”，不是“要不要休息”。
  2. CHOICE03–04【训练拉扯 / 现实帮助】：她想再来一轮时CHOICE03处理训练目标与身体状态的现实取舍；随后CHOICE04只决定你提供哪种具体帮助，不把休息包装成命令。
  3. CHOICE05–06【节奏怀疑 / 自己需求】：她说出对自己节奏的怀疑，CHOICE05回应事实、沉默或分享经验；CHOICE06轮到林昭宁说自己什么时候也会停，避免单向劝导。
  4. CHOICE07–08【她来结束 / 停一天的去处】：由她自己先收装备触发CG，CHOICE07处理你是否接她“今天到这儿”；CHOICE08只决定停下来以后一起去吃、走走或各自回去，让“停一天”成为她的主动。
- `ENDING_COOPERATIVE` 公开收束：停一天不是退步，继续练也不是逞强——重要的是这次决定真的是她自己的。
