- OPTION_ORDER_SEED：`CBACBACA`
- 开场：昕因为一次不理想的训练结果取消了原本的休息安排，打算独自加练。
- 关系核心：重点不是劝她积极，也不是趁她低落逼她表态；而是让她保有判断自己还能不能继续的主动权，同时让两个人都把“我愿意在你身边”说到足够具体。
- 固定戏剧弧：训练结果不理想→她把休息改成加练→现实疲劳让“坚持”与“停下”都不再是标准答案→她自己选定结束训练→两个人把之后这一小段时间留给彼此→若关系门满足，再进入明确关系选择。
- 角色新信息：昕面对挫败时会固执，但不是为了证明给别人看；她真正不喜欢的是别人因为她话少，就替她判断“你现在应该停”或“你现在应该需要我”。她真的想让一个人留下时，通常不会铺垫很长，而会把一句很轻的邀请说得比平时更明确。
- 高理解专属回报：她自己先说“今天到这儿”，收好装备后没有顺势说“我回去了”，而是看向你问“吃东西吗？”；你若没有替她解释，她会再补一句很轻的“我是问你，不是随便问个人”。
- 基础CG画面：训练场暮色压下来，她蹲在长椅边收好最后一件装备，起身后把自己手里的另一瓶水递给你。你伸手接时，她已经转身去拿外套。
- 高好感CG画面：训练场暮色里，她先收好装备，把水递到你手里，却没有立刻松开瓶身。她抬眼看你一下，等你接稳才收回手，随后把外套搭在臂弯里，站在原地问你“吃东西吗？”
- 低分仍有戏：低分线可让她继续练完，但第二天拿某个酸痛动作自嘲“昨天赢了训练，今天输给楼梯”；关系门不满足时也正常结束本章，不用失落对白惩罚玩家。
- 标题回收：“停一天也没关系”要由她本人用自己的动作和短句给出版本，不能由玩家教育式总结；关系确认若出现，也只能发生在她已经自己决定停下之后。
- 固定真相：无；本章禁止临场追加幕后真相或证据链。
- 固定四场：
  1. CHOICE01–02【异常看见 / 陪伴位置】：从她重复训练或明显慢下来进入，CHOICE01决定是否指出；CHOICE02只处理你待在场边、一起练最后一轮还是先去拿水，回答的是“怎么在旁边”，不是“要不要休息”。
  2. CHOICE03–04【训练拉扯 / 现实帮助】：她想再来一轮时CHOICE03处理训练目标与身体状态的现实取舍；随后CHOICE04只决定你提供哪种具体帮助，不把休息包装成命令。
  3. CHOICE05–06【节奏怀疑 / 双方需求】：她说出对自己节奏的怀疑，CHOICE05回应事实、沉默或分享经验；CHOICE06轮到林昭宁说自己此刻愿意留下到什么程度，避免单向照顾，也不给昕制造“必须接受帮助”的压力。
  4. CHOICE07–08【她来结束 / 停下来以后】：由她自己先收装备触发CG，CHOICE07处理你是否接她“今天到这儿”；CHOICE08只决定停下来以后一起吃、走走或各自回去。CHOICE08完成后先结算本章，再按 `C00 §1B` 判断是否出现关系确认固定选择。
