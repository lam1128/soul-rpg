> **章内权威：** OPTION_ORDER_SEED、开场、关系核心、故事弧、角色信息、高理解回报、CG、低分收束、标题回收、固定真相、8节点职责、局部分流与公开收束。

- 关系阶段：共同偏好与默契增加：允许旁人打趣，但不替玩家定义关系。
- OPTION_ORDER_SEED：`BCACABAC`
- 开场：城外训练区举办双人计时挑战，晨很自然地问你要不要一起。
- 关系核心：一场速度、体力和配合的共同冒险；输赢之外是“你能不能真的信任这个搭档”。
- 固定戏剧弧：赛前定节奏→顺利时互相逞强→环境干扰打破完美计划→冲线后发现真正默契是知道什么时候等半步。
- 角色新信息：晨有竞争心但并不迷恋漂亮成绩；真正压力下他会快速放弃原方案，而不是为了证明自己一直对。
- 高理解专属回报：关键时刻他不催你加速，而是主动把自己的节奏降半拍；赛后又装作只是“最优配速”，让可靠里出现一点嘴硬式幽默。
- 记忆画面锚点（CG）：冲线前他明明还有余力却主动降半拍，两个人几乎并肩跨过计时线；终点数字亮起时他第一眼看的不是成绩而是你。
- 低分仍有戏：低分线让你们几次互相等错时机，最后冲线时反而同时停了一下，成为最荒唐的“同步”。
- 标题回收：“双人计时”最后不能只报数字，要回收成两个人对“快”和“等”的共同尺度。
- 固定真相：无；本章禁止临场追加幕后真相或证据链。
- 固定四场：
  1. CHOICE01–02【赛前节奏 / 角色分工】：CHOICE01决定双人计时赛以冲成绩、稳完赛还是互相较劲进入；CHOICE02再具体分配开路、应变和体力管理，不重复目标。
  2. CHOICE03–04【顺风得意 / 速度分歧】：前段顺利，CHOICE03处理你们怎么互相激；第一次节奏分歧时CHOICE04只处理配速选择，让晨的可靠不是“自动正确”。
  3. CHOICE05–06【计划被打断 / 降半拍】：环境或魂兽打乱计划，CHOICE05重排比赛与安全；随后你或他状态变化，CHOICE06决定另一人是加速带、并肩降速还是换角色，埋下CG动作。
  4. CHOICE07–08【冲线方式 / 成绩之后】：CHOICE07决定最后冲线是各自拼、并肩还是保余量；CG里他主动降半拍，CHOICE08只处理成绩亮起后两个人先看什么、说什么，不用“更默契”总结。
- `ENDING_COOPERATIVE` 公开收束：你们开始知道对方什么时候会加速，也知道什么时候该等半步。
