> **章内权威：** OPTION_ORDER_SEED、开场、关系核心、故事弧、角色信息、高理解回报、CG、低分收束、标题回收、固定真相、8节点职责、局部分流与公开收束。

- 关系阶段：关系后续章：ROMANCE_ACTIVE=true时呈现已成立情侣版本；否则呈现同等完整的亲密伙伴版本。
- OPTION_ORDER_SEED：`BCACABAC`
- 开场：鬼鬼亲手做的一份小礼物在送出前不见了，她第一反应是拉你一起找。
- 关系核心：全线唯一调查章之一，低风险、偏轻喜剧；线索服务于行动默契，不做复杂犯罪谜案。
- 固定戏剧弧：礼物失踪→混乱现场与运输路线让搜寻充满她自己的痕迹→固定真相解除怀疑→找回后揭示礼物之外还有她真正舍不得丢的小心思。
- 角色新信息：鬼鬼做东西时并不总精细，但会偷偷在不起眼处加私人记号；她对“谁会看懂”很在意。
- 关系分流：
  - `ROMANCE_ACTIVE=true`：情侣版允许她把原本就很外显、很身体化的亲近自然升级，例如找线索时直接牵着你跑一小段、停下来还没立刻松手、找回东西后顺势勾住手臂或靠过来一起看盒子；但这些动作必须来自她本来的高能量和即时反应，不能把她写成只会撒娇或把恋爱变成幼稚化。
  - `ROMANCE_ACTIVE=false`：亲密伙伴版也必须保留她自然的身体性——兴奋时抓袖子、拉手腕、贴近一起看东西都可以，因为这本来就是她的人格；区别在于不自动加入持续牵手、恋人式依偎、情侣称呼或占有意味。朋友版不能为了区分恋爱而把她突然写得拘谨。
- 高理解专属回报：高理解线中，找回礼物时你先认出她藏的私人记号；她因此承认其中有一个小配件本来就是留给你的。情侣版可以让她承认后直接把那件东西塞到你手里并继续黏在旁边看你反应；伙伴版则保持她兴奋地催你马上试/看，但不额外赋予恋人语义。
- 记忆画面锚点（CG）：找回的礼物盒被打开，里面一个只有你们懂的私人记号重新露出来；她的手先盖上去又松开，承认其中有一件本来就是留给你的。
- 低分仍有戏：低分线让两人最后靠一个最离谱、最像她会留下的痕迹找到盒子，她会把你的错误推理记成“寻物黑历史”。
- 标题回收：“失踪的礼物”结尾不仅礼物回来，还要让一个只属于你们的记号再次出现。
- 固定真相：礼物盒与同色布景箱混在一起，被工作人员误送到隔壁活动场，并非有人拿走。
- 固定四场：
  1. CHOICE01–02【失物范围 / 私人记号】：CHOICE01限定礼物最后位置和真正接触人，避免无端怀疑；CHOICE02只处理先找外观、运输单还是她偷偷做的私人记号，建立验证路径。
  2. CHOICE03–04【混乱痕迹 / 线索分辨】：现场不断发现鬼鬼自己留下的混乱，CHOICE03决定哪些是笑点、哪些真相关；运输路线出现两种解释时CHOICE04只选择先验证哪条。
  3. CHOICE05–06【同色盒真相 / 时间压力】：确认被同色布景盒带走后CHOICE05处理如何快速取回；送礼时间逼近，CHOICE06只决定保完整惊喜、先赶时间还是当场改方案，不重复找盒。
  4. CHOICE07–08【礼物送出 / 私人物件】：礼物赶上送出后CHOICE07处理鬼鬼怎么面对自己这次乌龙；固定CG露出只有你们懂的记号，CHOICE08只回应她承认其中一件本来留给你的私人回报。结尾消费进入本章时已有的 `ROMANCE_ACTIVE` 分流，不再追加关系确认事务。
- `ENDING_COOPERATIVE` 公开收束：礼物找回来了，她也终于承认：有你一起找，连丢东西都没那么糟。
