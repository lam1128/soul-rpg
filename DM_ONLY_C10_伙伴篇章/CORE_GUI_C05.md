- 固定四场：
  1. CHOICE01–02【失物范围 / 私人记号】：CHOICE01限定礼物最后位置和真正接触人，避免无端怀疑；CHOICE02只处理先找外观、运输单还是她偷偷做的私人记号，建立验证路径。

  4. CHOICE07–08【礼物送出 / 私人物件】：礼物赶上送出后CHOICE07处理鬼鬼怎么面对自己这次乌龙；固定CG露出只有你们懂的记号，CHOICE08只回应她承认其中一件本来留给你的私人回报。
