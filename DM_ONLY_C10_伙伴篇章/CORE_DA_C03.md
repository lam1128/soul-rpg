- 开场：大突然宣布今天要做饭，并且坚称自己“绝对有谱”。
- 关系核心：厨房灾难、口味争执和共同收拾构成纯日常喜剧。
- 固定戏剧弧：“我有谱”的宣言→备菜连续翻车→成品偏离预想迫使两人决定怎么面对失败→边吃边收拾把灾难变成私人菜名。
- 角色新信息：大做饭会边做边改主意，把厨房当即兴现场；但他也有自己真正在乎的味道，不只是搞怪。
- 高理解专属回报：你们把意外成功的一小盘东西共同起一个离谱菜名，他认真宣布“这道只做给内测用户”，形成专属关系梗。
- 基础CG画面：厨房还乱着，唯一勉强成功的一小盘菜被端到桌中央。大拿着笔在一张纸上写菜名，旁边还压着切歪的食材和没收完的调料；你坐在桌另一边看着那盘成品。
- 高好感CG画面：唯一成功的小盘菜摆在桌中央，旁边压着你们刚写完的荒唐菜名。大把纸往你这边推，郑重其事地宣布“内测限定”，另一只手已经拿筷子示意你先尝。
- 低分仍有戏：低分线里几乎没有一道成功，两人最后靠最普通的主食救场，并把“今天谁做饭”永久列入高危话题。
- 标题回收：标题在结尾必须有一个荒唐答案：今天可能谁都没真正做成饭，但下一次责任怎么分已经成梗。
- 固定真相：无；本章禁止临场追加幕后真相或证据链。
- 固定四场：
  1. CHOICE01–02【菜单野心 / 掌勺权限】：大宣布“绝对有谱”，CHOICE01决定你信到什么程度；真正开火前CHOICE02只定谁掌哪一锅/哪一步，避免两题都问“让不让他做”。
  2. CHOICE03–04【备菜翻车 / 临时改谱】：第一轮小失误时CHOICE03处理你笑、救还是让他自己圆；他立刻想临时改菜单后CHOICE04只决定接受、限制或提出你的改法，让翻车继续升级。
  3. CHOICE05–06【成品偏航 / 失败态度】：成品与预想完全不同，CHOICE05只决定先尝、重做还是保留能吃部分；发现有一小盘意外好吃后CHOICE06处理你们怎么定义这次“成功”，不重复救厨房。
  4. CHOICE07–08【残局收拾 / 内测菜名】：CHOICE07处理谁收哪一片残局、是否继续互相甩锅；固定CG中唯一成功小盘配荒唐菜名，CHOICE08只回应他“内测限定”的私人邀请。
- `ENDING_COOPERATIVE` 公开收束：饭不一定成功，但“下次还敢一起做”已经很说明问题。
