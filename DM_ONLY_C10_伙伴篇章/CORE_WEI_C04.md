> **读取边界：** 仅当 `ACTIVE_EPISODE_ID` 或本轮明确进入目标等于本章ID时读取；运行其他章节时禁止预读本文件。
> **章内权威：** OPTION_ORDER_SEED、开场、关系核心、故事弧、角色信息、高理解回报、CG、低分收束、标题回收、固定真相、8节点职责、局部分流与公开收束。

- 关系阶段：关系确认章：整章以相处与选择为主，满足门槛后由玩家明确决定是否恋爱。
- OPTION_ORDER_SEED：`BACABCAC`
- 开场：一次普通训练后，晨提出去吃点东西再回去。你刚说还没想好吃什么，他已经顺手把两条路都算进回程，却又在下一秒发现自己把其中一家店的休息日记错了。
- 关系核心：关系确认章不靠危险逼近，而靠已经成为习惯的小事。晨的“稳”必须表现为能把现实条件想清楚、出错后也能立刻修正，而不是永远正确或把相处做成排表会议。
- 固定戏剧弧：训练后的默认同行→一个小算错让两个人先笑场→饭桌上各自未来计划第一次真正碰到一起→临时邀约制造现实分歧→回程确认“并肩”是否是双方主动选择。
- 角色新信息：晨把人在意进安排里的方式很实际：提前留时间、顺手多带一份东西、记得路线和先后；但他不会把这些动作端成承诺宣言。熟人面前他也会有低频冷梗、偶尔嘴瓢或算错一处，发现以后通常先笑一下再改，不会为了维持“可靠”形象硬撑。
- 高理解专属回报：他拿出一个已经替你留出空档的安排，又马上补一句“不是替你决定，你要不要来自己选”。你若拿他刚才记错休息日的事逗他，他会看一眼那页，顺手把错误划掉，说“所以才给你看，单人审核显然有风险。”
- 记忆画面锚点（CG）：回程的长街上两个人并肩走着，他手里的安排表有一处已经替你留空；旁边还有一行刚被划掉重写的时间。他先把那一页转给你看，再问要不要。
- 低分仍有戏：低分线里你们各按各计划走，最后却在同一个路口再次碰上；晨看一眼你、又看一眼路牌，只说“行，路线规划的说服力现在比较低”，不把不合拍升级成冷战。
- 标题回收：“并肩不是口号”必须用一个实际并肩动作/安排回收，而不是靠总结句；同时保留他会出错、会修正、会被你拆台的日常呼吸。
- 固定真相：无；本章禁止临场追加幕后真相或证据链。
- 固定四场：
  1. CHOICE01–02【旧默契回声 / 今晚安排】：训练收尾后CHOICE01处理熟悉的并肩动作/旧梗；发现其中一家店休息后，CHOICE02只决定今晚怎么临时改，不把“计划改变”写成情绪问题。
  2. CHOICE03–04【个人计划 / 把谁放进去】：谈下一阶段计划时CHOICE03只说林昭宁自己的目标；晨拿出他的安排后CHOICE04处理彼此是否给对方留位置，不能变成“谁牺牲”。
  3. CHOICE05–06【临时分歧 / 可靠边界】：回程临时邀约或计划冲突出现，CHOICE05处理现实取舍；晨习惯替你提前留空档时CHOICE06只回应这个动作——接受、调整或指出自己要决定，区别在合拍而非道德。
  4. CHOICE07–08【并肩画面 / 关系落点】：固定CG让有修改痕迹的安排表与并肩长街同框，CHOICE07处理你是否把自己的安排也给他看；CHOICE08只回答“下一阶段要不要继续把彼此算进去”。门槛满足后单独关系确认。
- `ENDING_COOPERATIVE` 公开收束：并肩不是一句承诺，也不是一张从不出错的表；是计划改了以后，你们还愿意把彼此重新算进去。
