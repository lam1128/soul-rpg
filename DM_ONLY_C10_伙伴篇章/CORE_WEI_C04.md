> **章内权威：** OPTION_ORDER_SEED、开场、关系核心、故事弧、角色信息、高理解回报、CG、低分收束、标题回收、固定真相、8节点职责、局部分流与公开收束。

- 关系阶段：关系确认章：整章以相处与选择为主，满足门槛后由玩家明确决定是否恋爱。
- OPTION_ORDER_SEED：`BACABCAC`
- 开场：一次普通训练后，晨提出去吃点东西再回去，你发现他已经默认把你的份也算进计划。
- 关系核心：关系确认章不靠危险逼近，而靠大量已经成为习惯的小事。
- 固定戏剧弧：训练后的默认同行→饭桌上各自未来计划第一次真正碰到一起→临时邀约制造现实分歧→回程确认“并肩”是否是双方主动选择。
- 角色新信息：晨把人在意进计划里的方式很实际：提前留时间、算路程、顺手带份东西；但他也会担心这种可靠被误读成理所当然。
- 高理解专属回报：他拿出一个已经替你留出空档的安排，又马上补一句“不是替你决定，你要不要来自己选”，第一次把在意和边界同时说清。
- 记忆画面锚点（CG）：回程的长街上两个人真正并肩走着，他手里的安排表有一处已经替你留空，却先把那一页转给你看再问要不要。
- 低分仍有戏：低分线里你们各按各计划走，最后却在同一个路口再次碰上；这次谁也不好意思再说是巧合。
- 标题回收：“并肩不是口号”必须用一个实际并肩动作/安排回收，而不是靠总结句。
- 固定真相：无；本章禁止临场追加幕后真相或证据链。
- 固定四场：
  1. CHOICE01–02【旧默契回声 / 今晚安排】：训练收尾后CHOICE01处理熟悉的并肩动作/旧梗；吃饭前CHOICE02只决定今晚怎么安排，让关系从日常进入未来话题而不突兀。
  2. CHOICE03–04【个人计划 / 把谁放进去】：谈下一阶段计划时CHOICE03只说林昭宁自己的目标；晨拿出他的安排后CHOICE04处理彼此是否给对方留位置，不能变成“谁牺牲”。
  3. CHOICE05–06【临时分歧 / 可靠边界】：回程临时邀约或计划冲突出现，CHOICE05处理现实取舍；晨习惯替你提前留空档时CHOICE06只回应这个动作——接受、调整或指出自己要决定，区别在合拍而非道德。
  4. CHOICE07–08【并肩画面 / 关系落点】：固定CG让安排表与并肩长街同框，CHOICE07处理你是否把自己的安排也给他看；CHOICE08只回答“下一阶段要不要继续把彼此算进去”。门槛满足后单独关系确认。
- `ENDING_COOPERATIVE` 公开收束：并肩不是一句承诺，而是你们已经做了很久的事。
