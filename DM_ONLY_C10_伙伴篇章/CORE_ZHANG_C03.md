- 关系阶段：暧昧可见：允许更私人关注和关系试探，但仍可自然停在朋友。
- OPTION_ORDER_SEED：`CBACBACA`
- 开场：昀原本排得很满的一天因为临时取消突然空了半天，他站在路口罕见地不知道接下来做什么。
- 关系核心：把一个习惯计划的人扔进没有计划的约会感日常，轻松而不嘲笑他的习惯。
- 固定戏剧弧：半天空白让他失去计划→不断小变化打碎临时安排→等待中谈到确定性与自由→最后由他本人主动安排一个“计划内的留白”。
- 角色新信息：昀不是讨厌随性，而是不习惯没有任何边界；一旦确认“今天可以浪费”，他可能比想象中更会玩。
- 高理解专属回报：他在自己的日程里认真写下一个没有具体内容的时间块，只标“和你”，然后拒绝继续定义要做什么。
- 基础CG画面：林昀的日程本摊在桌面上，一个规整的新时间块被空了出来。他拿着笔在格子顶端停了一会儿，你坐在旁边看着那块没有任务内容的空白。
- 高好感CG画面：日程本上的新时间块里只写了“和你”两个字，下面保持空白。林昀写完后把笔帽扣上，手掌盖住笔杆；你问要做什么时，他没有继续往格子里加任何内容。
- 低分仍有戏：低分线里两个人不断尝试制定新计划又不断失败，最后昀把当天总结成“计划执行率零，体验数据有效”，形成干式callback。
- 标题回收：“计划外半日”结尾必须真的进入他之后的计划，但保留内容为空。
- 固定真相：无；本章禁止临场追加幕后真相或证据链。
- 固定四场：
  1. CHOICE01–02【接受空白 / 第一件随性事】：半天突然空出来，CHOICE01处理是否允许“今天没目标”；CHOICE02只决定第一件随性小事，不让两题都围绕要不要计划。
  2. CHOICE03–04【计划被打碎 / 临时改法】：第一处变化让临时计划失效，CHOICE03处理昀如何重排、你如何参与；第二处变化时CHOICE04只决定要不要干脆停止继续排表，让调整与放下成为不同节点。
  3. CHOICE05–06【确定性偏好 / 浪费许可】：等待中CHOICE05交换两人对确定性的具体偏好；昀问“这样算不算浪费时间”时CHOICE06只回应你对这半天本身的价值，不教他学随性。
  4. CHOICE07–08【时间块 / 内容留白】：固定CG里他写下一个只标“和你”的空白时间块，CHOICE07处理你是否追问内容；他扣上笔帽后CHOICE08只回答这个留白下次要不要真的保留。
- `ENDING_COOPERATIVE` 公开收束：计划外的半日，最后反而被他认真记进了以后。
