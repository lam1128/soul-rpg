- 开场：猎手协会一枚用于集合的旧银哨突然不见了，鸥本来只想帮忙找回来。
- 关系核心：全角色线唯一的调查型篇章之一；规模小、无凶案，调查服务于两人的配合与玩笑。
- 固定戏剧弧：普通失物→几条轻量线索和互相拆台→固定真相推翻“被偷”想象→找回银哨后把调查默契拉回生活关系。
- 角色新信息：鸥调查时很细，但不会因为直觉强就抢结论；熟人面前她会拿你过度推理或漏掉的小细节开很冷的玩笑。
- 高理解专属回报：找回后她把银哨先递给你试吹，自己在旁边嫌声音难听，却明确说下次这类小麻烦还是找你。
- 记忆画面锚点（CG）：银哨找回后，她站在路边把哨子先递到你嘴边让你试吹；声音响起时她嫌弃地皱眉，却没把哨子立刻收回。
- 低分仍有戏：低分线可让你们对线索一路判断相反，最后谁也没资格得意；银哨一响就自动触发互相翻旧账。
- 标题回收：银哨在结尾必须真的响一次，并成为两人召集/互相提醒的旧梗，而不是找回后直接入库。
- 固定真相：维修后的银哨被老教员放进新人奖品盒，之后奖品盒被临时挪库。
- 固定四场：
  1. CHOICE01–02【问题限定 / 首条验证】：CHOICE01先限定是普通失物、误放还是确有他人拿取，不把猜测写成偷窃；找到最后出现地点后，CHOICE02只选择第一条验证路径——现场、经手人或维修记录，承担不同时间成本。
  2. CHOICE03–04【人物询问 / 线索分歧】：接触相关人时CHOICE03决定问法和分寸；拿到两条互相不完全吻合的信息后，CHOICE04让你和鸥各自给出解释并决定先验证哪一个，允许真实分歧，不用好感直接判谁对。
  3. CHOICE05–06【假设更新 / 找盒策略】：确认银哨并非被偷后，CHOICE05处理你们怎样更新判断、如何向被怀疑者收回先前猜测；奖品盒又被临时挪库，CHOICE06只处理怎么找盒子，不能再次讨论“谁判断更好”。
  4. CHOICE07–08【误会修复 / 银哨回收】：找回后CHOICE07决定怎样把误会落地修复；银哨必须真正响一次并进入固定CG，CHOICE08只处理这个声音以后在你们之间要变成什么小梗/召集方式。
- `ENDING_COOPERATIVE` 公开收束：银哨找回来了，真正留下的是你们面对小麻烦时越来越像一组人的节奏。
