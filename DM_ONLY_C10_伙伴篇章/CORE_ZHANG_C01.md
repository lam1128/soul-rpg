# CORE_ZHANG_C01｜单章故事卡

> **公开标题/题材/解锁/前置：** 只读 `DM_ONLY_C00_伙伴篇章库.md#1A` 当前 `CHAPTER_ID` 行；本文件不复制公开导航元数据。
> **读取边界：** 仅当 `ACTIVE_EPISODE_ID` 或本轮明确进入目标等于本章ID时读取；运行其他章节时禁止预读本文件。
> **章内权威：** OPTION_ORDER_SEED、开场、关系核心、故事弧、角色信息、高理解回报、CG、低分收束、标题回收、固定真相、8节点职责、局部分流与公开收束。

- 关系阶段：熟悉建立：可以轻松、有默契，但不强制暧昧。
- OPTION_ORDER_SEED：`CABACBCA`
- 开场：昀拿来一套新出的桌面推演题，坚称其中至少有一题答案写错了。
- 关系核心：这是游戏和斗嘴，不是案件；两个人可以为了一个毫无现实后果的答案认真得过分。
- 固定戏剧弧：错误答案争论→双方过度认真地抓漏洞→各自犯错让“谁更聪明”失去意义→最后把下一套题/晚饭变成更想一起做的事。
- 角色新信息：昀解题时会真的兴奋，也会一本正经把一个荒唐假设推到底；他有玩心，不是只有分析模式。
- 高理解专属回报：他明知你给了一个不够“标准”的解法，却把它留在答案旁边写一句“可玩性更高”，第一次让好玩压过唯一正确。
- 记忆画面锚点（CG）：答案纸上一个被判“错”的解法旁边，他没有划掉，而是认真添了一句“可玩性更高”；两份不同答案第一次并排被保留下来。
- 低分仍有戏：低分线里你们坚持不同答案到最后才发现题册印错页码；两个人的长篇论证一起作废，成为最佳干式笑点。
- 标题回收：“错误答案”结尾必须证明至少有一个“错”反而留下了更值得保留的东西。
- 固定真相：无；本章禁止临场追加幕后真相或证据链。
- 固定四场：
  1. CHOICE01–02【接题姿态 / 第一解法】：昀拿来“有错答案”的题，CHOICE01决定你认真挑战、故意唱反调还是当游戏玩；CHOICE02才选择自己的第一套解法/假设，不重复“做不做题”。
  2. CHOICE03–04【抓漏洞 / 自己犯错】：互相抓漏洞时CHOICE03处理你是否借机逗他的过度认真；随后你或昀被证明漏了一步，CHOICE04只处理面对自己犯错的态度，让输赢先松下来。
  3. CHOICE05–06【方法差异 / 好玩优先】：题目暴露两人做决定方式不同，CHOICE05只讨论一处具体差异；出现一个不标准但更有趣的解法时CHOICE06决定是否保留它，不再争谁聪明。
  4. CHOICE07–08【错误答案保留 / 下一套题】：固定CG中“错解”旁出现“可玩性更高”，CHOICE07处理你怎么接他这次让步；CHOICE08只决定下一套题/下一顿饭是否继续一起，标题从错误变成被保留的东西。
- `ENDING_COOPERATIVE` 公开收束：答案改没改不重要，他已经开始默认最想和你对答案。
