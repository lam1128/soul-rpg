- 关系阶段：关系后续章：ROMANCE_ACTIVE=true时呈现已成立情侣版本；否则呈现同等完整的亲密伙伴版本。
- OPTION_ORDER_SEED：`CABACBCA`
- 开场：学院一场公开计时赛出现两份互相矛盾的成绩表，几名参赛者因此争得不可开交。
- 关系核心：这是撒线唯一的调查型篇章；重点是还原事实与保护当事人，不把它升级成刑侦剧。
- 固定戏剧弧：两份成绩表冲突→多个合理假设竞争→固定真相推翻作弊想象→公开修正后回到两个人如何面对自己判断出错。
- 角色新信息：撒会快速提出很多假设，但真正证据出来时也能比很多人更快修正，不把面子放在事实前面。
- 关系分流：
  - `ROMANCE_ACTIVE=true`：情侣版保留他高反应、爱辩、爱抓矛盾的节奏，亲密只从已经成立的默契里自然冒出来，例如争论中直接把纸推到你面前、说完一串反例后又很自然地问你的判断、在人群散开后短暂碰一下手背或肩膀。真正重要的问题上他仍应主动收掉修辞、变短、变直接；禁止恋爱后突然变成高频甜言蜜语或所有争论都让着你。
  - `ROMANCE_ACTIVE=false`：亲密伙伴版同样保留高强度智力互搏、直接欣赏与私人问题；两个人可以互相拆台、押不同假设、承认各自算错，但不自动加入情侣专属身体亲密或恋人称呼。朋友版不能因为没有恋爱就削弱他对你能力的信任。
- 高理解专属回报：真相确认前他主动让你先讲最终判断，并真的不抢着补充；这是对你能力的直接信任。情侣版可以在你说完以后只低声补一句很私人、很短的确认；伙伴版则用一句干净的“我同意”或直接接你的验证路径，不能重新抢回舞台。
- 基础CG画面：结果修正后，最后一题的答案纸已经收好。撒把其中一张翻到背面，拿笔写下一行新问题，纸面旁边没有计时器、成绩表或其他证据；你坐在对面看着他落笔。
- 高好感CG画面：撒在答案纸背面写完那个没有标准答案的问题，直接把纸转过来推到你面前。笔横在纸边，他的手没有收回；情侣版允许手背短暂碰到你的手边，伙伴版保持纸和笔直接交到你这一侧，不追加情侣专属接触。
- 低分仍有戏：低分线里你们各自押错一个假设，真相出来后只能争“谁错得比较高级”，保留调查后的轻松关系味。
- 标题回收：“最后一题”结尾必须变成撒留给你的一个非调查问题，答案不由证据决定。
- 固定真相：暴雨后终点标记被维护人员挪回错误位置，两份记录实际上基于不同终点，不存在作弊。
- 固定四场：
  1. CHOICE01–02【问题限定 / 第一记录】：CHOICE01限定“哪份计时有效”，明确不是抓作弊者；CHOICE02只选择先核对计时器、记录员或赛道标记中的一条，承担验证顺序。
  2. CHOICE03–04【记录比较 / 假设竞争】：CHOICE03处理与相关人沟通时的方式；几组记录出现矛盾后CHOICE04让你和撒提出不同假设并押一条先验，不把争论当感情测试。
  3. CHOICE05–06【暴雨改写 / 责任处理】：发现暴雨挪动终点标记后CHOICE05更新判断并决定如何证明；确认无作弊后CHOICE06只处理怎样向被怀疑者/参赛者说明，不再争谁猜对。
  4. CHOICE07–08【结果修正 / 最后一题】：公开修正结果后CHOICE07处理撒是否还想辩裁定；固定CG在答案纸背面出现“没有证据可查”的私人最后一题，CHOICE08只回答那一题，把调查拉回两个人。结尾消费进入本章时已有的 `ROMANCE_ACTIVE` 分流，不再追加关系确认事务。
