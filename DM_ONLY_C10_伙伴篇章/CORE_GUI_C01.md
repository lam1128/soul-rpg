# CORE_GUI_C01｜单章故事卡

> **公开标题/题材/解锁/前置：** 只读 `DM_ONLY_C00_伙伴篇章库.md#1A` 当前 `CHAPTER_ID` 行；本文件不复制公开导航元数据。
> **读取边界：** 仅当 `ACTIVE_EPISODE_ID` 或本轮明确进入目标等于本章ID时读取；运行其他章节时禁止预读本文件。
> **章内权威：** OPTION_ORDER_SEED、开场、关系核心、故事弧、角色信息、高理解回报、CG、低分收束、标题回收、固定真相、8节点职责、局部分流与公开收束。

- 关系阶段：熟悉建立：可以轻松、有默契，但不强制暧昧。
- OPTION_ORDER_SEED：`CBACBACA`
- 开场：鬼鬼宣布今天的路线全由她决定，然后第一站就临时改了三次。
- 关系核心：热闹、临时起意和彼此配合是主菜；玩家不是负责收拾她的“家长”。
- 固定戏剧弧：她宣布今天全听她的→路线连续变更制造高能量喜剧→一个小麻烦让“听她的”不能等于你负责善后→最后一站反过来把决定权交给你。
- 角色新信息：鬼鬼的随性不是没判断：她会很快发现什么不好玩、什么值得改路线，也愿意直接承认“刚刚那个主意不行”。
- 高理解专属回报：最后她忽然说“这一站听你的”，但又偷偷准备了一个小惊喜；既让出决定权，又保留她的主动感。
- 基础CG画面：最后一站前，鬼鬼把画满改路线记号的路线纸塞到你手里，自己往后退了半步。她两只手空出来摊在身侧，抬着下巴看你，等你决定最后往哪走。
- 高好感CG画面：鬼鬼把路线纸塞进你手里，退开半步宣布“这一站听你的”。她另一只手却还藏在身后，露出已经准备好的小惊喜一角；她看着你忍不住先笑了出来。
- 低分仍有戏：低分线里你们一路互相改对方路线，最后地图被画得像毛线团；她把这张失败路线图郑重保存当纪念。
- 标题回收：“今天听你的”结尾必须发生主语反转：究竟谁听谁的已经不重要，决定权能来回流动。
- 固定真相：无；本章禁止临场追加幕后真相或证据链。
- 固定四场：
  1. CHOICE01–02【接随机行程 / 决定权交换】：鬼鬼拿出随机路线时CHOICE01决定你怎么接她的兴奋；CHOICE02才明确今天哪些站她定、哪些站你定或轮流定，不能把高分写成全听她。
  2. CHOICE03–04【走错笑点 / 小游戏投入】：走错方向或进错店，CHOICE03处理你们如何把错误继续玩；到小游戏摊时CHOICE04只决定你认真比、故意搞怪还是另提玩法，不重复路线决定权。
  3. CHOICE05–06【真麻烦 / 一起善后】：一个随机计划真的造成轻麻烦，CHOICE05决定现实上先解决什么；鬼鬼开始自己补救时CHOICE06处理你怎么和她一起承担，而不是单方面替她收拾。
  4. CHOICE07–08【安静最后一站 / 今天听谁的】：最后一站突然安静，CHOICE07处理她说“今天最好玩的其实不是地点”时你怎么接；固定CG她把路线纸塞给你并说“这一站听你的”，CHOICE08只决定最后一站去哪。
- `ENDING_COOPERATIVE` 公开收束：路线乱七八糟，但一起走的人越来越确定。
