- 开场：一次普通训练判断没有达到蓉自己的预期，她表面照常，私下却把同一页记录翻来覆去看了几遍。
- 关系核心：不是安慰“你没错”，也不是把她当成需要被拯救的人；而是两个人能不能一起把事实看清，同时让她在不完美、不确定和被看见这些状态里仍保有自己的判断。关系推进必须来自她主动把一部分没整理好的自己留给你看，而不是玩家替她总结情绪。
- 固定戏剧弧：训练判断不理想→她反复复盘把自己困住→事实与自我要求出现缝隙→她承认一处真实疏漏，也承认不是所有变量都能被照顾周全→她自己合上记录本→若关系门满足，再把“为什么愿意让你留下”说到足够明确并进入关系选择。
- 角色新信息：蓉最难接受的不只是犯错，而是没有办法把每个变量都照顾周全。她认真时很容易把问题拆得很细，真正放松反而表现为允许某一格暂时空着、允许一句话没组织好就先说出来。
- 高理解专属回报：她主动合上记录本，留下一处没写完的空格，先说“明天再看”。过了一会儿又把本子往你这边推了一点，说“你明天也可以提醒我——不是提醒答案，提醒我别又坐到这么晚。”
- 基础CG画面：灯下的记录本停在一个没写完的空格，顾蓉一只手压着页角，另一只手握着笔。她盯着那一行看了一会儿，把笔帽扣上，却还没有合本子。
- 高好感CG画面：灯下的记录本停在一个没写完的空格，顾蓉主动合上本子，把笔夹在那一页。她没有把本子收回自己面前，而是留在你们两个人之间，指尖还压着封面边缘。
- 低分仍有戏：低分线里她仍把复盘做完，却把你某句不合时宜的话圈起来当“反例”，第二天平静拿来吐槽；关系门不满足时也正常结束，不用“你不懂我”之类惩罚式台词。
- 标题回收：“不必总是正确”结尾必须出现一个被她主动保留的未完成/未确定项；不能由旁白宣布她终于学会了接受错误。
- 固定真相：无；本章禁止临场追加幕后真相或证据链。
- 固定四场：
  1. CHOICE01–02【反复检查 / 是否介入】：从她重复检查同一件小事进入，CHOICE01决定你是否指出；CHOICE02只处理怎么介入——陪核对、让她讲、先做别的，不把“别想太多”当答案。
  2. CHOICE03–04【事实复盘 / 责任边界】：CHOICE03只核对真实发生的事实；当一处确实有她的疏漏时，CHOICE04处理怎样承认影响又不把全部责任无限扩大。
  3. CHOICE05–06【可靠恐惧 / 双方不完美】：她承认害怕被看见“不够可靠”，CHOICE05回应具体经历而非空泛安慰；CHOICE06轮到林昭宁说一个自己的不完美或现实限制，让关系变成双方都能被看见，而不是单向治疗。
  4. CHOICE07–08【留下空格 / 明天再看】：CHOICE07处理下一步现实行动由她自己决定；固定CG中她主动合上留有空格的记录本，CHOICE08只回应“明天再看”以及她是否愿意把明天的一小段也留给你。CHOICE08完成后先结算本章，再按 `C00 §1B` 判断是否出现关系确认固定选择。
