- 关系阶段：暧昧推进：关系更近，但不提前执行确认门。

- 开场：一次普通训练判断没有达到蓉自己的预期，她表面照常，私下却反复复盘。
- 关系核心：重点不是安慰“你没错”，而是陪她面对失误、责任和自我要求。
- 固定戏剧弧：训练判断不理想→她反复复盘把自己困住→事实与自我要求出现缝隙→她自己决定停止继续证明“我还能找出一个答案”。
- 角色新信息：蓉最难接受的不只是犯错，而是没有办法把每个变量都照顾周全；她真正放松时会允许某个问题暂时没有结论。
- 高理解专属回报：她主动合上记录本，留下一处没写完的空格，说明“明天再看”，这是比任何安慰都更大的关系信号。
- 记忆画面锚点（CG）：灯下记录本停在一个没写完的空格，她看了很久后主动合上本子，把笔夹在那一页；高理解版只说“明天再看”，不再补答案。
- 低分仍有戏：低分线里她仍把复盘做完，却把你某句不合时宜的话圈起来当“反例”，第二天平静拿来吐槽，避免苦情收尾。
- 标题回收：“不必总是正确”结尾必须出现一个被主动保留的未完成/未确定项。
- 固定真相：无；本章禁止临场追加幕后真相或证据链。
- 固定四场：
  1. CHOICE01–02【反复检查 / 是否介入】：从她重复检查同一件小事进入，CHOICE01决定你是否指出；CHOICE02只处理怎么介入——陪核对、让她讲、先做别的，不把“别想太多”当答案。
  2. CHOICE03–04【事实复盘 / 责任边界】：CHOICE03只核对真实发生的事实；当一处确实有她的疏漏时，CHOICE04处理怎样承认影响又不把全部责任无限扩大。
  3. CHOICE05–06【可靠恐惧 / 玩家不完美】：她承认害怕被看见“不够可靠”，CHOICE05回应具体经历而非空泛安慰；CHOICE06轮到玩家说一个自己的不完美/限制，避免单向治疗。
  4. CHOICE07–08【留下空格 / 明天再看】：CHOICE07处理下一步现实行动由她自己决定；固定CG中她主动合上留有空格的记录本，CHOICE08只回应“明天再看”这次主动停止，不再开总结会。
