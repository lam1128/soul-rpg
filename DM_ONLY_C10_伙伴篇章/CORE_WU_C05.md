- 开场：你和昕最近连续几次“刚好顺路”，这次连她自己都先笑了。
- 关系核心：一条重复走过的路变成关系确认章：没有外部大事，只看两个人还要不要继续装成巧合。
- 固定戏剧弧：又一次“刚好顺路”→旧章习惯自然回声→中段两个人都意识到巧合已经太多→最后决定是否还要继续用“顺路”当借口。
- 角色新信息：昕熟悉后会用很淡的方式主动，比如提前站在你常经过的地方，却仍能一本正经说是巧合。
- 高理解专属回报：她看着你先笑一下，直接承认“今天其实不顺路”，把主动权放在一句非常轻的实话里。
- 记忆画面锚点（CG）：本来应该分开的路口，她停在明显不顺路的方向，先看你一眼再笑，说“今天其实不顺路”，随后仍站在你这边。
- 低分仍有戏：低分线里两个人继续坚持“顺路”，结果各自为了圆这个说法多绕一截路，形成只有双方心知肚明的荒谬结尾。
- 标题回收：标题必须在结尾被否定或承认：“刚好顺路”究竟还是不是巧合。
- 固定真相：无；本章禁止临场追加幕后真相或证据链。
- 固定四场：
  1. CHOICE01–02【旧习惯回声 / 今日路线】：开场用窗边/慢走等旧章习惯回声，CHOICE01决定你怎么接熟悉感；出门后CHOICE02只决定今天这条“顺路”具体往哪走，不直接问关系。
  2. CHOICE03–04【临时约会感 / 是否改道】：遇到吃东西或小活动，CHOICE03处理谁先提议；活动结束后CHOICE04只决定是否为了彼此明显绕一点路，让暧昧落在行动。
  3. CHOICE05–06【安静停留 / 未来频率】：一处安静停留里CHOICE05处理“以后还要不要这样走”的具体频率/形式；她给出很轻的真话后CHOICE06只回应自己的意愿，不做关系定义。
  4. CHOICE07–08【不顺路揭穿 / 最后一步】：固定CG前CHOICE07处理你什么时候发现今天根本不顺路；她笑着承认后CHOICE08只回答你还要不要继续往同一个方向走。满足门槛后再进入关系确认事务。
- `ENDING_COOPERATIVE` 公开收束：所谓顺路，到这里已经足够让人选择要不要承认。
