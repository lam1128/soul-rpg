- 关系阶段：关系后续章：`ROMANCE_ACTIVE=true` 时呈现已经确认关系后的情侣版本；否则呈现同等完整的亲密伙伴版本。本章不承担首次恋爱确认。
- OPTION_ORDER_SEED：`BACABCAC`
- 开场：你和昕最近连续几次“刚好顺路”，这次她已经提前站在你常经过的路口，看到你以后自己先笑了。
- 关系核心：不是再问“要不要在一起”，而是看已经明确的关系怎样落进低噪音的日常主动里。无论情侣还是亲密伙伴，她都不是靠高频表达证明亲近；区别要落在她愿意为你多走哪一段、留下多久，以及是否自然使用只有情侣关系才成立的亲密动作。
- 固定戏剧弧：她提前等在路口→两个人故意继续叫它“顺路”→临时吃东西/小活动让路线越绕越远→安静停留里各自提出下一段安排→回到分岔口时由她亲手揭穿“今天根本不顺路”。
- 角色新信息：昕熟悉后会用很淡的方式主动：提前几分钟等你、记得你大概从哪边来、没有大事也会把脚步慢下来。进入恋爱后她也不会突然变得黏人或话很多，亲密更多是默认把你算进自己的路线里。
- 关系分流：
  - `ROMANCE_ACTIVE=true`：她不再需要拿“巧合”保护关系身份，但仍会把“顺路”当两个人的旧梗。允许出现低调的情侣动作，例如走窄路时自然牵一下手、等人群过去才松开，或停下时肩膀靠近而不专门解释；禁止突然高频撒娇、占有式查问或长篇情话。
  - `ROMANCE_ACTIVE=false`：两个人依然可以主动绕路、等对方、共享安静时间，她也可以承认“今天其实不顺路”；但不自动加入情侣专属身体接触，不把亲密伙伴线写成失败恋爱或遗憾补偿。
- 高理解专属回报：她看着你先笑一下，直接承认“今天其实不顺路”。情侣版说完后仍继续往你这边走，经过人多的地方时短暂牵住你的手；伙伴版则把手插回口袋，轻轻偏一下头示意“走啊”，两版都由她主动把下一段路留下来。
- 基础CG画面：本来应该分开的路口，沈昕停在明显不属于她回程的那一侧。路牌立在她身后，她看一眼你来的方向，又低头用鞋尖碰了碰路边石沿，没有转身离开。
- 高好感CG画面：本来应该分开的路口，沈昕站在你要走的那一侧，先看你一眼再笑。她抬手指了指与你同方向的街口，说“今天其实不顺路”，话说完却已经先往那边迈了一步。
- 低分仍有戏：一路不太合拍时，两个人仍会为了圆“顺路”这个说法各自多绕一截；昕发现后会很平静地说“那今天算路线规划失败”，让旧梗留下，不把关系状态写崩。
- 标题回收：标题必须在结尾被她本人揭穿或继续拿来当旧梗；情侣版的“顺路”是双方明知故犯的借口，伙伴版的“顺路”是她愿意主动多陪一段的轻松说法。
- 固定真相：无；本章禁止临场追加幕后真相或证据链。
- 固定四场：
  1. CHOICE01–02【提前等人 / 今日路线】：开场用她提前在路口出现承接旧习惯，CHOICE01决定你怎么接她这次主动；CHOICE02只决定今天先往哪走，不再测试关系身份。
  2. CHOICE03–04【临时活动 / 明显绕路】：遇到吃东西或小活动时CHOICE03处理谁先提议；活动结束后CHOICE04只处理是否继续绕路以及谁先承认已经偏离原路线。
  3. CHOICE05–06【安静停留 / 各自安排】：一处安静停留里CHOICE05处理两个人怎么共享不说话的时间；CHOICE06各自说一件接下来真实要做的事，避免情侣版退化成全天黏在一起，也避免伙伴版只有客套。
  4. CHOICE07–08【不顺路揭穿 / 下一段路】：固定CG前CHOICE07处理你什么时候发现今天根本不顺路；她主动承认后CHOICE08只决定这一段路还要怎么走到结束。结尾消费进入本章时已有的 `ROMANCE_ACTIVE` 分流，不再追加关系确认事务。
- `ENDING_COOPERATIVE` 公开收束：她没有把主动变成很大的动静，只是终于不再需要“刚好”两个字才能站到你这边。
