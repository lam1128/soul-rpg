- 关系阶段：共同偏好与默契增加：允许旁人打趣，但不替玩家定义关系。
- OPTION_ORDER_SEED：`CABACBCA`
- 开场：大接了一个需要把演出器材送到外城的短差事，问你要不要同行。
- 关系核心：路途、器材和临时状况构成冒险；他的脑洞可以解决问题，也会制造新问题。
- 固定戏剧弧：装车分工→一路唱歌争路线把差事玩成旅程→环境风险让脑洞必须真正解决问题→返程把“跑调”变成两个人的搭档暗号。
- 角色新信息：大的怪点子并非都没用；他在压力下会突然抓到别人没想到的侧路，但也能承认某个点子真的只是在添乱。
- 高理解专属回报：他把一路乱唱里唯一一次两个人同时接上的节奏命名为“合拍段”，之后用它当返程暗号。
- 记忆画面锚点（CG）：返程车上一路跑调的歌声里，某一小段你们突然同时接上同一个节奏；大立刻用手在车板上敲出那几拍，给它命名成只属于你们的“合拍段”。
- 低分仍有戏：低分线里你们一路谁都没跟上谁的节奏，最后却在抱怨同一句事时突然同步，成为最意外的“合拍”。
- 标题回收：“一路都在跑调”结尾必须出现一次真正的合拍，但不要求音乐意义上的唱准。
- 固定真相：无；本章禁止临场追加幕后真相或证据链。
- 固定四场：
  1. CHOICE01–02【同行姿态 / 装车分工】：大问你要不要一起送器材，CHOICE01处理你是把它当差事、旅程还是现场节目；装车时CHOICE02只分谁管易碎、路线与临时调整，不重复“要不要同行”。
  2. CHOICE03–04【跑调玩心 / 路线争执】：上路后CHOICE03决定你接不接他的乱唱/节奏游戏；真正遇到路线分歧时CHOICE04只处理选哪条和谁说服谁，让玩心与策略分开。
  3. CHOICE05–06【风险救场 / 脑洞筛选】：环境风险打断旅程，CHOICE05先决定安全与器材优先级；大抛出一个怪方案后CHOICE06只处理你怎么判断它是妙招、半可用还是纯添乱，不能把高分写成无条件支持。
  4. CHOICE07–08【抵达结果 / 合拍段】：送达后CHOICE07处理任务结果与一路翻车怎么评价；返程固定CG出现唯一同步节奏，CHOICE08只决定要不要接他命名的“合拍段”作为以后暗号。
- `ENDING_COOPERATIVE` 公开收束：一路跑调，搭档没跑。
