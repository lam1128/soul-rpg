# CORE_DA_C04｜单章故事卡

> **公开标题/题材/解锁/前置：** 只读 `DM_ONLY_C00_伙伴篇章库.md#1A` 当前 `CHAPTER_ID` 行；本文件不复制公开导航元数据。
> **读取边界：** 仅当 `ACTIVE_EPISODE_ID` 或本轮明确进入目标等于本章ID时读取；运行其他章节时禁止预读本文件。
> **章内权威：** OPTION_ORDER_SEED、开场、关系核心、故事弧、角色信息、高理解回报、CG、低分收束、标题回收、固定真相、8节点职责、局部分流与公开收束。

- 关系阶段：关系确认章：整章以相处与选择为主，满足门槛后由玩家明确决定是否恋爱。
- OPTION_ORDER_SEED：`CBACBACA`
- 开场：一次热闹聚会散场后，大忽然问你：跟他待久了会不会觉得累。
- 关系核心：关系确认章从搞笑落到认真，但不把他的快乐一面写成面具或病症。
- 固定戏剧弧：热闹散场→他用玩笑试探“跟我待着累不累”→玩家真实回应无法用哄人代替→最后他主动决定哪些自己要改、哪些不想被改。
- 角色新信息：大真正被触动时会突然少说，不一定用更大的段子遮住；安静几秒对他来说可以比长篇告白更明显。
- 高理解专属回报：高理解线中他听完后不接梗，只说一句很简单的“那你别走太快”，随后才自己嫌这句话太正经。
- 基础CG画面：热闹散尽的走廊里，大站在离你几步的位置，手里还捏着刚才聚会剩下的小道具。他张了张嘴像要再接一句玩笑，却停住，只看着你没有马上转身。
- 高好感CG画面：空下来的走廊里，大难得没有接第二个梗，只站在原地对你说“那你别走太快”。说完他自己先皱了下脸嫌这句话太正经，却仍看着你，没有把话收回去。
- 低分仍有戏：低分线让两人对某些习惯真的谈不拢，大最后给其中一个习惯起“不可协商项目”怪名，边界和笑点同时留下。
- 标题回收：“别改我”结尾必须区分“接受这个人”与“现实习惯仍可协商”，不是一句无条件包容。
- 固定真相：无；本章禁止临场追加幕后真相或证据链。
- 固定四场：
  1. CHOICE01–02【热闹余波 / 麻烦习惯】：聚会散场先收垃圾/道具，CHOICE01处理两个人怎么从热闹落到独处；大拿一个具体麻烦习惯自嘲时CHOICE02只回应这件具体事，不直接问“你累不累”。
  2. CHOICE03–04【玩笑试探 / 真嫌弃处】：他用更大玩笑试探你是否觉得他难相处，CHOICE03处理你接梗还是拆梗；CHOICE04只让林昭宁说出一个自己确实会嫌弃/需要协商的现实点，避免无条件包容答案。
  3. CHOICE05–06【不必改 / 可以改】：大第一次认真区分“我不想被改掉的部分”和“我自己也想调整的部分”，CHOICE05只接前者；CHOICE06只接后者，让接受与协商成为两个不同问题。
  4. CHOICE07–08【安静几秒 / 关系落点】：固定CG前CHOICE07处理他突然少说的几秒；他说“那你别走太快”后CHOICE08只回应这句关系主动。满足门槛后单独关系确认，不再解释“别改我”的寓意。
- `ENDING_COOPERATIVE` 公开收束：喜欢一个人不等于把他改成最好管理的版本。
