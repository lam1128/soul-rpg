- 关系阶段：暧昧可见：允许更私人关注和关系试探，但仍可自然停在朋友。
- OPTION_ORDER_SEED：`CBACBACA`
- 开场：晨的护具要修、训练服要补、还要买一堆杂物，他干脆问你“借半天行不行”。
- 关系核心：跑腿变成约会感最容易发生的地方：一堆小事、不断临时改计划、互相嫌弃又互相等。
- 固定戏剧弧：半天跑腿清单→条理与临时变化不断冲突→延误让“完成任务”不再可能→最后保留一个非必要停留，证明半天不只是借来办事。
- 角色新信息：晨会认真列清单，但也会被某个小东西或突发念头拐走；稳的人偶尔跑偏才是他的反差。
- 高理解专属回报：事情办完后他主动说“还没到半天”，把剩下的时间拿来做一件完全没写在清单上的事。
- 记忆画面锚点（CG）：半日清单已经全部划掉，纸的最下面却多出一行原本不存在的小停留；他看看天色，说“还没到半天”，把笔收起来不再补任务。
- 低分仍有戏：低分线里你们为清单顺序争到最后，结果最重要的一项反而忘了，返程一路互相怪对方，笑点比完美效率更值钱。
- 标题回收：“借你半天”结尾必须算一次时间：剩下、超时或“下次再借”，形成明确callback。
- 固定真相：无；本章禁止临场追加幕后真相或证据链。
- 固定四场：
  1. CHOICE01–02【清单顺序 / 谁来掌表】：半天 errands 摊开，CHOICE01决定先后优先级；CHOICE02只决定清单由谁拿、谁可以临时改，不重复“怎么安排时间”。
  2. CHOICE03–04【试用互损 / 等待偏好】：试护具或买零碎时CHOICE03处理彼此具体评价；等待修理时CHOICE04只处理空档想做什么，暴露非任务偏好。
  3. CHOICE05–06【延误取舍 / 计划外请求】：修理延误时CHOICE05决定删哪项/延哪项；事情终于办完时晨提出一个非必要小停留，CHOICE06处理你是否接这次计划外，不再谈效率。
  4. CHOICE07–08【清单清零 / 剩余半天】：清单全部划掉后CHOICE07处理“还剩时间”的第一反应；固定CG里他写入额外一行又收笔，CHOICE08只决定这段剩余时间属于什么。
- `ENDING_COOPERATIVE` 公开收束：东西都修好了，最难归还的反而是被他借走的那半天。
