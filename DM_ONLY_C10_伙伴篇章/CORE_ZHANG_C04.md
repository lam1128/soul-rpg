- 关系阶段：暧昧推进：关系更近，但不提前执行确认门。
- OPTION_ORDER_SEED：`BACABCAC`
- 开场：训练器材库的数量记录连续三天对不上，负责人请昀帮忙看看是不是有人违规领用。
- 关系核心：昀线唯一调查型篇章；规模局限在一次记录异常，重点是逻辑与不先定罪。
- 固定戏剧弧：数量异常被误读成违规→多组记录支持不同假设→固定真相暴露口径问题→修正流程后把“合理”重新定义为愿意接受别人提醒。
- 角色新信息：昀进入解题模式时可能暂时忽略人的感受，但他并不抗拒被纠正；真正信任的人可以在他算得最投入时打断他。
- 高理解专属回报：在最终结论前他主动把记录推给你，说“你先找我哪里可能算错”，把自我校验交给你一部分。
- 记忆画面锚点（CG）：仓库记录摊满桌面，他把自己那本计算册和笔一起推到你面前，说“你先找我哪里可能算错”；手离开本子后没有立刻收回。
- 低分仍有戏：低分线里你们各自坚持一套模型到真相出现，最后发现两人都在不同地方漏看；回程争“谁漏得更不合理”成为旧梗。
- 标题回收：“唯一不合理的地方”结尾要从仓库记录回收到昀自己承认“我的模型也可能是不合理的那个”。
- 固定真相：夜班交接把待修器材在两套表中采用了不同口径，形成重复差额，并不存在违规领用。
- 固定四场：
  1. CHOICE01–02【问题定义 / 流程核对】：CHOICE01限定“数量为什么对不上”而非默认违规；CHOICE02只选择先核对领用、维修还是交接流程，建立验证顺序。
  2. CHOICE03–04【三天记录 / 模型分歧】：CHOICE03处理你和昀如何拆三天记录；各自模型得出不同解释后CHOICE04只决定先验证哪一个，并允许彼此指出盲点。
  3. CHOICE05–06【口径真相 / 被误会的人】：确认待修器材被双重口径计算后CHOICE05更新模型并固定真相；CHOICE06只处理如何向被误会的人说明/修复流程，不能继续沉迷证明谁算对。
  4. CHOICE07–08【自我校验 / 不合理回收】：固定CG前CHOICE07处理昀主动把计算册推给你让你找错；CHOICE08只回收“唯一不合理的地方”——允许自己的模型也成为待验证对象。
- `ENDING_COOPERATIVE` 公开收束：最不合理的地方被找到了，而你们都没有为了证明自己聪明去制造一个坏人。
