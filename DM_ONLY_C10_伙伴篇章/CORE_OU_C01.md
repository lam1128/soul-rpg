> **章内权威：** OPTION_ORDER_SEED、开场、关系核心、故事弧、角色信息、高理解回报、CG、低分收束、标题回收、固定真相、8节点职责、局部分流与公开收束。

- 关系阶段：熟悉建立：轻松、互相拆台、能开始形成只属于两人的小习惯；不强制暧昧。
- OPTION_ORDER_SEED：`CBACBACA`
- 开场：晨练结束后你和鸥都饿了，学院外街的小摊这一锅刚好只够最后两份葱油拌面。鸥先抬起两根手指示意“正好两份”，随即把这顿普通早饭变成一场很小的比赛。
- 关系核心：不是学习“正确尊重边界”，而是两个人能不能把普通吃饭玩出自己的节奏：敢互相逗、看得见对方的小偏好、出事故时接得住彼此，也允许各自有自己的吃法。
- 固定戏剧弧：最后两份与靠墙座位的小竞争→拌面口味和结账方式把胜负欲继续往前推→抢赢的座位偏偏不断出小事故，两个人从互相拆台变成一起救场→回学院时开场的“两根手指”变成下一顿饭的双方暗号。
- 角色新信息：鸥吃面有很具体的小习惯：先把葱油拌匀再决定要不要加醋；她总抢靠墙的位置，不是为了控制场面，而是晨练后喜欢靠着墙慢慢吃、看一会儿街上，不急着马上回训练场。熟了以后，她不会一本正经解释这些偏好，而会把它们拿来和你打赌、翻旧账。
- 本章高理解锚点：愿意和她玩但不只跟着她；能注意她真实的吃饭节奏而不是替她安排；发生小事故时会一起救而不是接管；听懂她想多坐一会儿是在享受普通相处，而不是等一个“正确沟通答案”。
- 高理解专属回报：回学院岔路时，鸥已经走出两步，却自己倒着走回来，先抬起开场那两根手指，直接说“下次还是两份，座位重赛。”她不等你提下次，也不解释为什么，只把下一顿自然地算进两个人的以后。
- 记忆画面锚点（CG）：清晨学院岔路，街后的炊烟还没散，鸥背着晨光倒着走两步，抬起两根手指朝你比出开场“最后两份”的手势；高理解版由她先说“下次还是两份，座位重赛”，普通版只保留轻松邀约，摩擦版则把事故不断的靠墙座郑重“让”给你，但三条路线都让“两份”成为可被一眼认出的共同旧梗。
- 低分仍有戏：一路不太合拍时，她不会冷淡退场，而是在离开前一本正经宣布“下次两份可以，那张靠墙座归你，我绝对不抢”，把整顿饭不断翻车的座位变成带刺但好笑的长期梗。
- 标题回收：场景4必须再次明确出现“两份”，并与开场两指手势呼应；不能只写“以后再吃”。高理解线的“两份”代表她主动预留下一次，低分线的“两份”仍保留共同经历但不假装关系已经很近。
- 固定真相：无；本章禁止临场追加幕后真相或证据链。
- 固定四场：
  1. CHOICE01–02【进入姿态 / 玩笑竞争】：晨练后听到只剩两份，CHOICE01决定你怎么接她把吃饭变成小比赛；到摊前她抢靠墙座，CHOICE02决定你怎么跟她继续这个游戏。两题都不能写成“去不去吃”或“谁有权替谁决定”。
  2. CHOICE03–04【口味观察 / 互惠方式】：面上桌后，鸥那套“先拌匀再加醋”的吃法自然露出来；CHOICE03围绕你怎么接她这个具体习惯，而不是考记忆答案。随后两个人同时准备结账，CHOICE04只处理这一顿怎么付——AA、临时赌一把、谁输谁请等都可合理化，不能提前讨论下一顿规则。
  3. CHOICE05–06【共同救场 / 私人闲暇】：抢赢的靠墙桌偏偏有条腿不稳，调料与两碗面出现一次真实但轻量的连锁险情；CHOICE05决定你们怎么一起救场。事后鸥才说自己为什么总爱这个位置、为什么晨练后故意吃慢一点；CHOICE06处理你是否接住“她其实喜欢这样浪费一点时间”的私人信息，不得再变成边界协商。
  4. CHOICE07–08【旧梗回收 / 下一次关系动作】：吃完走回学院，鸥先拿“今天抢座的战绩”翻旧账，CHOICE07决定你怎么把这顿饭的事故变成双方旧梗。到岔路触发固定CG锚点；CHOICE08只回答她用“两根手指”递来的下一顿邀请，不再制定谁等谁、谁先结束修炼之类详细合作守则。
- 局部分流要求：场景3起，`WARM` 版让鸥主动把一个调料/桌面位置让给你或与你同步救场；`NEUTRAL` 版保持自然分工；`FRICTION` 版可以互相嫌弃对方救场方式，但事故本身与后续私人信息都必须完整发生，不能删掉场景。
- `ENDING_COOPERATIVE` 公开收束：两碗面吃完以后，你们没有得到一套“正确相处规则”，只多了一个很具体的默契——下次再看到两根手指，就知道该一起去吃饭了。
