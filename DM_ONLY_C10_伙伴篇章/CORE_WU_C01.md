- 关系阶段：熟悉建立：可以轻松、有默契，但不强制暧昧。
- OPTION_ORDER_SEED：`ACBCABCB`
- 开场：学院休息厅只剩窗边一张双人桌，昕已经坐在那里。
- 关系核心：没有任务，只有一段从“拼个桌”慢慢变成两个人都没急着走的下午。
- 固定戏剧弧：拼桌的低压开场→安静里逐渐出现只对熟人才有的冷幽默→一次外部拼座/借桌打断舒适区→天色变化时两个人都没急着离开。
- 角色新信息：昕的安静不是无所谓：她对座位、光线、饮料和说话节奏都有具体偏好，只是不抢着宣布。
- 高理解专属回报：她主动把原本放在两人中间的东西挪到同一侧，示意你坐近一点一起看；动作比长对白更像她。
- 基础CG画面：窗边的光落在双人桌上，昕坐在靠窗一侧，书和几样小东西原本横在你们中间。她低头把其中一本合上，手指停在桌面中央，你坐在对面看着她整理。
- 高好感CG画面：窗边光线已经斜下来，昕把原本横在两人中间的书和物件全部收到自己同一侧，又用指尖轻轻点了点身旁空出来的位置；她没有多说，只抬眼看向你。
- 低分仍有戏：低分线里你们始终没找到同一个聊天频率，但窗边的阳光移动迫使两人一起挪椅子，留下一个平静又有点荒谬的共同动作。
- 标题回收：“窗边那个位置”结尾必须变化：可以从对坐变并坐，或她下次自然替你留出那一侧。
- 固定真相：无；本章禁止临场追加幕后真相或证据链。
- 固定四场：
  1. CHOICE01–02【坐不坐下 / 开场方式】：窗边空位出现时CHOICE01决定你以什么距离坐下或先停在旁边，不能把靠近自动等于高分；坐定后CHOICE02只处理第一句怎么开——聊书、聊窗外、分享东西或安静待着。
  2. CHOICE03–04【共同话题 / 沉默节奏】：书、饮料或训练声提供话题，CHOICE03决定你是否把一个具体兴趣递给她；对话自然停下来后CHOICE04只处理你能不能让沉默成立，而不是再次找话题。
  3. CHOICE05–06【拼座压力 / 她的选择】：有人来借桌或拼座，CHOICE05处理你是否先替她答、一起调整或让她自己决定；她做出选择后CHOICE06只回应她的实际偏好，不复盘边界。
  4. CHOICE07–08【收东西 / 窗边位置】：天色变化准备离开，CHOICE07处理谁先走与是否同路；固定CG里她把中间物件收向同一侧，CHOICE08只回应下次这个窗边位置是否还算“刚好有空”。
- `ENDING_COOPERATIVE` 公开收束：窗边的位置没有被谁占有，但后来你们都更容易坐到同一边。
