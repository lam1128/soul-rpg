- 关系阶段：共同偏好与默契增加：允许旁人打趣，但不替玩家定义关系。
- OPTION_ORDER_SEED：`BCACABAC`
- 开场：学院开放一套双人机关训练场，单靠计算或单靠反应都过不去。
- 关系核心：公开挑战、共同解题与适度危险构成冒险，不设置幕后真相。
- 固定戏剧弧：入场分工→前几关模型有效让他越算越顺→条件突变迫使完美方案失效→最后一关接受不完美但共同可行的答案。
- 角色新信息：昀在模型失效时会短暂兴奋而非只挫败；他其实享受“重新算”的瞬间，也能被玩家的直觉真正说服。
- 高理解专属回报：最后一关他在你一句简短信号后直接放弃自己算到一半的方案执行你的版本，过关后才开始复盘为什么。
- 记忆画面锚点（CG）：最后一道双人机关前，两个人各按住一侧控制件；他在你给出短信号后放弃算到一半的方案，机关开启的瞬间才抬头看结果。
- 低分仍有戏：低分线里两人各自算对一半，却因为不同步把最简单机关搞复杂；出场后他认真给这次失败写出过度精确的命名。
- 标题回收：“双人机关课”结尾必须落在只有两个人互相让出一步才成立的那一道机关上。
- 固定真相：无；本章禁止临场追加幕后真相或证据链。
- 固定四场：
  1. CHOICE01–02【入场目标 / 执行分工】：CHOICE01决定这套机关课以成绩、挑战极限还是磨合为目标；CHOICE02才分观察、试探、执行职责，不重复“谁听谁”。
  2. CHOICE03–04【模型优势 / 玩家独立解】：前几关昀的计算有效，CHOICE03处理你如何参与而不是当执行器；出现一关你先看到另类解法时CHOICE04只处理是否坚持、试验或让他验证，建立双向能力。
  3. CHOICE05–06【模型失效 / 简短信号】：条件突变让原方案失效，CHOICE05只决定重算、试探或先保安全；最后一关你给出短信号时CHOICE06处理他是否立即跟、要求说明或改半步，为CG的“先执行后复盘”做铺垫。
  4. CHOICE07–08【机关开启 / 不完美答案】：固定CG机关在未完全计算下开启，CHOICE07处理过关后的第一反应；CHOICE08只回收“双人机关课”——下一次谁可以先说一句“我有个不完美答案”。
- `ENDING_COOPERATIVE` 公开收束：你们不是因为想法一样才过关，而是知道什么时候该让对方改自己的答案。
