- 关系阶段：关系确认章：整章以相处与选择为主，满足门槛后由玩家明确决定是否恋爱。
- OPTION_ORDER_SEED：`ACBCABCB`
- 开场：撒找你继续上次没完的辩题，结果两个人从公开场合一路争到只剩彼此。
- 关系核心：关系确认章：玩笑可以很多，但最后必须让真正的问题不被笑过去。
- 固定戏剧弧：从旧辩题进入熟悉节奏→旁人一句关系玩笑把真正问题带上桌→夜里只剩两人时撒第一次主动停掉修辞→最后把无法辩赢的问题交给玩家选择。
- 角色新信息：撒越在意越可能先用逻辑和玩笑绕；真正认真时反而会突然变短、不给自己留台阶。
- 高理解专属回报：他自己说“这个我不辩了”，然后用最普通的一句话问你想要什么，让主动收掉语言优势成为专属回报。
- 基础CG画面：夜里只剩你和撒，写满论点的纸还摊在桌面。他一手拿着笔，另一只手已经按住纸角，刚才写到一半的句子停在那里；你坐在桌对面看着他。
- 高好感CG画面：夜里只剩两个人，撒把一直拿来记论点的纸合上，手掌压在封面上，笔也被放到一旁。他抬头直视你，只说一句“这个我不辩了”。
- 低分仍有戏：低分线里两人又把认真问题绕成辩论，临走前撒突然指出“我们刚才谁都没回答”，留下一个未解决但有张力的尾巴。
- 标题回收：“辩不过你”不是他逻辑输了，而是结尾明确出现一件不能靠辩赢来决定的事。
- 固定真相：无；本章禁止临场追加幕后真相或证据链。
- 固定四场：
  1. CHOICE01–02【旧辩题回声 / 今晚新题】：用熟悉的辩论节奏开场，CHOICE01处理谁先挑起旧梗；CHOICE02只决定今晚真正值得吵的一个生活/未来问题，不直接问关系。
  2. CHOICE03–04【旁人一句 / 双方接场】：旁人随口问“你们什么关系”，CHOICE03处理当场怎么接而不让NPC定义；人走后CHOICE04只处理你们要不要继续拿这句开玩笑，或暂时绕开。
  3. CHOICE05–06【收掉玩笑 / 真实问题】：夜里撒第一次主动收住梗，CHOICE05只回应他“这个我不辩了”的动作；CHOICE06才回答他关于未来/彼此的真实问题，避免连续两题都在关系确认。
  4. CHOICE07–08【合上论点纸 / 你的选择】：固定CG中论点纸被合上，CHOICE07让林昭宁也提出一个自己的问题或要求；CHOICE08只给本章关系落点。门槛满足后再单独进入恋爱确认。
