# CORE_GUI_C02｜单章故事卡

> **公开标题/题材/解锁/前置：** 只读 `data/companions/DM_ONLY_C00_伙伴篇章库.md#1A` 当前 `CHAPTER_ID` 行；本文件不复制公开导航元数据。
> **读取边界：** 仅当 `ACTIVE_EPISODE_ID` 或本轮明确进入目标等于本章ID时读取；运行其他章节时禁止预读本文件。
> **章内权威：** OPTION_ORDER_SEED、开场、关系核心、故事弧、角色信息、高理解回报、CG、低分收束、标题回收、固定真相、8节点职责、局部分流与公开收束。

- 关系阶段：共同偏好与默契增加：允许旁人打趣，但不替玩家定义关系。
- OPTION_ORDER_SEED：`BACABCAC`
- 开场：鬼鬼拿到一张公开的旧训练场寻宝图，坚持要你一起去找终点箱。
- 关系核心：这是明确的寻宝冒险，不是调查案：地图是真的、目标公开，乐趣在路上。
- 固定戏剧弧：公开寻宝图出发→走错路和机关把兴奋拉高→环境风险迫使两人重排“宝藏”和安全→终点箱普通到好笑，真正奖励落在一路共同经历。
- 角色新信息：鬼鬼直觉快，也会因为太兴奋错过显眼提示；她可以第一个发现异常，也可以第一个大叫“我刚刚怎么没看到”。
- 高理解专属回报：她在寻宝图背面直接画上“下次”的起点，并把你的名字/符号圈进去，完全不装成临时起意。
- 基础CG画面：寻宝终点的箱子打开在地上，里面的奖品普通得有些好笑。鬼鬼蹲在箱子旁把寻宝图翻到背面，拿笔在空白处画出一个新的起点，你站在旁边低头看着。
- 高好感CG画面：鬼鬼把寻宝图翻到背面，在新画出的起点旁补上你的名字或符号，又用笔圈了一整圈。她抬起地图给你看，终点箱还开在脚边，笔帽咬在另一只手里。
- 低分仍有戏：低分线里终点到了才发现你们一路各自理解了不同的地图图例，宝箱没多好，两个人争图例争得最好笑。
- 标题回收：“寻宝图”结尾必须成为下一次共同路线的载体，而不是找到箱子后报废。
- 固定真相：无；本章禁止临场追加幕后真相或证据链。
- 固定四场：
  1. CHOICE01–02【地图态度 / 装备取舍】：CHOICE01决定你对她那张不太靠谱的寻宝图有多认真；CHOICE02只处理装备和安全准备，避免“信不信地图”重复两次。
  2. CHOICE03–04【走错路线 / 地形机关】：第一次走错路时CHOICE03决定回头、绕成新路线还是拿来开玩笑；遇到小机关后CHOICE04处理谁先试、谁观察，让她的直觉和你的判断都能发挥。
  3. CHOICE05–06【风险排序 / 宝物取舍】：环境风险或魂兽出现，CHOICE05只重排安全与寻宝目标；安全后发现一条更快但更冒险的近路，CHOICE06只处理要不要为“宝”多冒一点险，不重复战斗决定。
  4. CHOICE07–08【普通奖品 / 下一张图】：终点箱奖品普通得好笑，CHOICE07处理你们如何评价这趟“亏不亏”；固定CG她在地图背面画下一次起点，CHOICE08只回答这个新起点要不要把你圈进去。
- `ENDING_COOPERATIVE` 公开收束：宝箱里是什么不重要，重要的是她已经开始默认下一张图也会有你。
