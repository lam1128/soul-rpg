# DM ONLY｜魂兽数据库


> 物种模板是静态真值。具体个体第一次生成时按年份计算并冻结；不随玩家等级重新缩放。

> **文件职责：** 魂兽物种静态数据库、个体生成模板、能力与魂环倾向。
> **权威范围：** 物种模板；具体遭遇个体生成后冻结到运行状态，不随玩家情况重缩放。
> **读取策略：** `SELECTIVE_ON_MATCH`，只读取当前候选/遭遇魂兽及生成接口。

> **生成合法性：** 普通随机候选必须先由 `R00` 证明物种在当前区域普通表中、年份同时落入当前分区与本物种年份范围，再使用本文件生成数值。未登记 `SPECIES_ID` 不能以 runtime 临时物种身份进入 ACTIVE 遭遇；历史异常实例的兼容只读取 `12`。

## 1. 个体数值生成

对年份 `Y`、物种倍率 `H/A/D/S`：

- `基础HP = 220 + 20×sqrt(Y) + 0.25×Y`
- `基础ATK = 30 + 2.1×sqrt(Y)`
- `基础DEF = 18 + 1.4×sqrt(Y)`
- `基础魂力 = 120 + 4×sqrt(Y) + 0.04×Y`
- 个体最终值分别乘物种倍率并四舍五入。
- `KILL_XP` 只按 `10 §10` 的经验公式与本物种 `XP系数` 计算。

战斗技能的倍率/消耗随后按物种条目执行。

## 3. 魂环技能候选生成接口

玩家到瓶颈猎魂时，读取魂兽标签 + 主角武魂类型，生成一张唯一候选卡并在击杀前冻结。优先把魂兽最鲜明的能力映射为该武魂能使用的形式；不复制原作角色已有的专属魂技名。

同一 `SOUL_BEAST_INSTANCE_ID + MARTIAL_SOUL_ID` 在冻结后不得重算。
